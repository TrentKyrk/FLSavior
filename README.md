# FLSavior
A place for publicly documenting guides, files, and solutions to repairs and upgrades of FLSUN printers.

Currently this endeavor is new but will work as follows:
1. each project included here will either be a repair or an upgrade of an FLSUN printer
2. each project will include tags that indicate what printer, part, and problem it pertains to
3. each project will include the necessary instructions, parts, tools, and safety information related to the repair/upgrade
